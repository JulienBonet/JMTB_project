### > project infos

JMDB (Julius Movie DataBase) is a personal movie library manager that lets you import films from the TMDB API, organize your collection, and explore it through advanced filters (genre, country, year, cast, crew, studios, keywords, and more). It also supports custom collections, physical storage tracking, and YouTube trailers, providing cinephiles with a rich and searchable personal film database.
